## Установлення для дискової версії (Complete)

0. *(Опціонально)* Зробіть резервну копію гри.
1. Зайдіть до папки `Для заміни Дискової`.
2. Скопіюйте **вміст** папки `Civilization 4 Complete` до вашої папки гри (яка, ймовірно, називатиметься так само) зі злиттям і заміною файлів.
3. Очистіть кеш, затиснувши клавішу **Shift** під час запуску гри.
4. Можна грати!


## Установлення для Steam-версії

1. Зайдіть до бібліотеки Steam.
2. Знайдіть у списку ігор:
   - «Sid Meier's Civilization IV»,
   - «Sid Meier's Civilization IV Warlords» або
   - «Sid Meier's Civilization IV Beyond the Sword»,

   і клацніть на ній правою кнопкою миші.
3. У меню, що з'явилося, оберіть: **Управління → Переглянути локальні файли**.
4. Відкрийте нове вікно провідника та зайдіть до папки `Для заміни Steam`.
5. Скопіюйте **вміст** папки зі злиттям і заміною файлів до вашої папки гри (яка має називатися так само) з пункту 3.
6. Очистіть кеш, затиснувши клавішу **Shift** під час запуску гри.
7. Можна грати!

> **Примітка.** Після відновлення цілісності файлів у Steam (ПКМ на гру зі списку → Властивості → Інстальовані файли → Перевірка цілісності файлів гри) українізатор потрібно встановити повторно.


## Перший запуск

Незалежно від вашого попереднього досвіду гри в Sid Meier's Civilization IV, після встановлення українізатора в грі, ймовірно, буде англійська мова.

Щоб змінити мову гри:

1. Запустіть гру.
2. Натисніть **ADVANCED** у головному меню.
3. Натисніть **OPTIONS**.
4. Унизу вікна, що з'явилося, знайдіть випадне меню з написом «English» біля «Language» та натисніть на нього.
5. Оберіть **Ukrainian (Українська)**.

Якщо ви раніше грали в Sid Meier's Civilization IV, то могли помітити, що текст став трохи більшим. На великих екранах із роздільною здатністю 4K (3840 × 2160 пікселів) рекомендую ставити щонайбільше 2K (2560 × 1440 пікселів), щоб уникнути надто дрібного масштабу.


## Зміна розміру шрифту

> **Зверніть увагу:** наступні кроки є прямим втручанням у системні файли гри, за дії з якими ви несете відповідальність самі. Проте не хвилюйтеся, якщо написали зайвого: будь-якої миті ви можете поставити українізатор знову.

### Повернути класичний вигляд гри

1. Відкрийте в провіднику папку з грою.
2. Перейдіть за шляхом: `Resource` → `Themes` → `Civ4`.
3. Видаліть файл `Civ4Theme_Common.thm`.
4. Знайдіть і перейменуйте файл `1_original-Civ4Theme_Common.thm` на `Civ4Theme_Common.thm`.

### Налаштувати розмір шрифту самостійно

1. Повторіть перші два пункти попередньої інструкції.
2. Відкрийте файл `Civ4Theme_Common.thm`.
3. Знайдіть у тексті `Sylfaen`.
4. Змінюйте числа (розмір шрифту) в рядках, що містять `Sylfaen`.


## Вирішення проблем

Якщо в головному меню ви бачите приблизно такий текст: `ÎÄÈÍÎ÷ÍÀ ÃÐÀ`, або в самій грі не відображаються літери, або не завантажуються збереження з кирилицею в назві, виконайте наступні кроки.

### Windows 11

1. Відкрийте налаштування Windows.
2. Перейдіть до розділу: **Час і мова → Мова і регіон**.
3. Відкрийте випадне меню, клацнувши на «Мова інтерфейсу Windows».
4. Для пункту «Мова програм, які не підтримують Юнікод» установіть українську, білоруську, російську, болгарську, македонську чи сербську (кирилиця).
5. Вимкніть перемикач біля «Бета-версія: використовувати Unicode UTF-8 для підтримки мови по всьому світу».

   > **Примітка.** Це діє на **всі** старі програми.

### Windows 10

1. Відкрийте налаштування Windows.
2. Перейдіть до розділу: **Час і мова → Мова**.
3. У пов'язаних налаштуваннях знайдіть і натисніть «Адміністративні налаштування мови».
4. Натисніть кнопку «Змінити мовні параметри системи…».
5. Для «Поточні мовні параметри системи» встановіть українську, білоруську, російську, болгарську, македонську чи сербську (кирилиця).
6. Приберіть позначку біля «Бета-версія: використовувати Unicode UTF-8 для підтримки мови по всьому світу».

   > **Примітка.** Це діє на всі старі програми на комп'ютері.
7. Перезавантажте систему.
